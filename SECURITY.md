# Security policy

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository. If GitHub reporting is unavailable, email [hraness@pm.me](mailto:hraness@pm.me). Include the affected revision, reproduction steps, impact, and any suggested mitigation. We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

The site is static, has no accounts, and keeps no product database. The research data is public. Reports about the accuracy of a record or a source are not security vulnerabilities and can use a normal issue or the contact page.
